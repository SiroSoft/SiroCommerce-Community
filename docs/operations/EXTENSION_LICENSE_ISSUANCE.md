# Extension License Issuance

Status: PRIVATE. License issuance, key custody, rotation, revocation and
commercial license delivery are Pro-only operational material.

This public Community mirror documents only the offline verification foundation
used by the core:

- licenses are signed JSON envelopes verified offline;
- runtime enforcement happens on Pro extension enable/update;
- no private key, license document or customer license data is public.

Operators who need issuance/custody instructions must use the private
SiroCommerce-Pro repository or the private operations channel.
