# Exception Register

Exception IDs are immutable: `EXC-NNN`. An exception is a temporary approved
deviation, never a way to relabel a failed control.

| ID | Control | Deviation | Risk ID | Compensating control | Owner | Approver | Expires | Status |
|---|---|---|---|---|---|---|---|---|
| EXC-001 |  |  |  |  |  |  |  | OPEN |

Required fields for approval: scope, affected versions/environments, reason,
residual risk score, remediation issue, due date, monitoring, and approver.
Expired exceptions automatically block release.
