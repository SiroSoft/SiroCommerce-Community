# CG-004 CMS Content Guarantees

CG-004 covers typed CMS revision diffs, optimistic merge conflicts, idempotent autosave, scheduling states, and media metadata validation.

- Revision diffs return field-level `{ field, from, to }` changes within one commerce scope.
- Autosave and merge require `Idempotency-Key`; replaying an equivalent key returns the original page result.
- `expected_version` protects autosave and merge. A stale version returns HTTP 409 with `current_version` and `expected_version`.
- Page states are `draft`, `scheduled`, `published`, and `archived`. Scheduled pages require `scheduled_at`.
- Media references are metadata only. Each reference requires an HTTPS URL, supported MIME type, positive size up to 50 MiB, and optional positive dimensions. CG-004 does not provide or claim external storage.

The generated OpenAPI documents and TypeScript SDK are refreshed with `composer generate:openapi --working-dir backend` and `composer generate:sdk --working-dir backend`.
